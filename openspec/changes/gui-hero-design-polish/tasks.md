# Tasks

This change starts after `gui-music-artist-page` has merged to `main`. Each unit may leave dependent callers or the build broken for the next unit. A unit records that state in its handoff. Tests follow `crates/mbv-gui/AGENTS.md` and `docs/invariants/14-test-ownership.md`: hermetic, no live mpv, no sleeps, one contract per test, and an existing test or `#[case]` table extends before a new test starts. No lint suppression, no `allow` or `expect` attribute. Run `cargo fmt` after each Rust edit. Run cargo commands in the foreground and do not pipe them. The artboards are in `openspec/changes/gui-hero-design-polish/canvas/`. Keep every font family, size, and weight as it is now (design D2), except the playing row's title weight (design D6).
