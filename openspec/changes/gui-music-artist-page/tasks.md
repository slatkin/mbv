# Tasks

Each unit may leave dependent callers or the build broken for the next unit. A unit records that state in its handoff. Core work is in `crates/mbv-client-core`; every other change is in `crates/mbv-gui`. Verifications name `-p mbv-client-core` or `-p mbv-gui`. Tests follow `crates/mbv-gui/AGENTS.md` and `docs/invariants/14-test-ownership.md`: hermetic, no live mpv, no sleeps, one contract per test, and an existing test or `#[case]` table extends before a new test starts. No lint suppression, no `allow` or `expect` attribute. Run `cargo fmt` after each Rust edit. Run cargo commands in the foreground and do not pipe them. Never run cargo in the background and never sleep or poll for it.
