# Tasks

Each unit may leave dependent callers or the build broken for the next unit. A unit records that state in its handoff. Tests follow `docs/invariants/14-test-ownership.md`: add a test only for a contract that no other test owns. Core tests use the App stub and the hermetic client seam that `src/app/tests/gui_library_tv.rs` uses. No live Service, no sleeps.
