# Tasks

Each unit may leave dependent callers or the build broken for the next unit. A unit records that state in its handoff. Tests follow `docs/invariants/14-test-ownership.md`: a test owns one contract that no other test owns, and it tests state or behaviour. Add no test that only checks that a DOM node is present or where it sits, unless the requirement is about which controls show. GUI core tests live in `crates/mbv-gui/src/gui_core/tests/` and use the `MockHttp` transport and the helpers that `gui_library_tv.rs` and `test_support.rs` use. Core tests live in `crates/mbv-client-core/src/app/tests/`. No live Service, no sleeps, no lint suppression, no `allow` or `expect` attribute. No crate `mbv` exists: every verification names `-p mbv-gui` or `-p mbv-client-core`.
