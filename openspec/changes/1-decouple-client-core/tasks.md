# Tasks

Run every cargo command in the foreground and wait for it to finish. Do not background it, sleep, or poll. Run `cargo fmt` after each Rust change. Move files with `git mv` so history follows them. Keep the module layout rules in `AGENTS.md` (no `mod.rs`, no `#[path]`, no `include!`). Add no lint suppression. Each group ends with the workspace green: `cargo check --workspace --all-targets` and `cargo clippy --workspace --all-targets -- -D warnings` pass. A test moves with the code it owns; add a test only where a task names its contract. Before you dispatch a row, check its premises (the symbols and files it names) against the code.
