# Tasks

## Execution rules

Dispatch one row to one fresh worker. Rows are edit-only: a row is complete when its named edits exist and its own `rg` check, if it has one, passes. The workspace may stay broken between rows. A row edits at most about six files by hand. A row marked **Sweep** is a mechanical rename or import change across any number of files: do it with search-and-replace, follow the compiler errors that it causes, and make no other change. The last row of each group is a **Gate**. It runs the group's checks and fixes the errors that remain, including test files that the group's rows changed signatures under. If errors remain in more than about six files, the gate does not fix them. It reports the failing files and the row that owns each one, and that row is dispatched again. Before you dispatch a row, check its premises (the symbols and files it names) against the code. If a file list grew past the six-file bound, split the row before you dispatch it.

Run every cargo command in the foreground and wait for it to finish. Do not background it, sleep, or poll. Run `cargo fmt` after each Rust change. Move files with `git mv` so history follows them. Keep the module layout rules in `AGENTS.md` (no `mod.rs`, no `#[path]`, no `include!`). Add no lint suppression. A test moves with the code it owns. Add a test only where a row names its contract. No row changes a test expectation. Every gate runs `cargo check --workspace --all-targets`, `cargo clippy --workspace --all-targets -- -D warnings`, and the nextest packages it names.
